# 大盘条（Market Strip）设计

> 状态：**设计稿，未实现**。视觉稿见 [market-strip-mock.html](market-strip-mock.html)（用浏览器直接打开，离线可用，含浅/深色切换和各状态）。
> 目标：在网页版最上方加一条 30px 的长条，常驻显示 A 股三大指数、两市成交额，以及相对昨日同时段的放量/缩量。

## 1. 数据源（已验证可用，2026-09-18）

全部是东财公开行情接口，返回 JSON，无需 Cookie，请求头带 `User-Agent` + `Referer: https://quote.eastmoney.com/` 即可。与现有股吧抓取一样属于非官方接口，随时可能变。

| 用途 | 接口 | 关键字段 |
|---|---|---|
| 实时行情（批量） | `https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&secids=1.000001,0.399001,0.399006,1.000300&fields=f2,f3,f4,f5,f6,f12,f14,f17,f18` | `f2` 最新价、`f3` 涨跌幅 %、`f4` 涨跌额、`f5` 成交量（手）、`f6` 成交额（元）、`f12` 代码、`f14` 名称、`f17` 今开、`f18` 昨收 |
| 5 分钟 K 线（跨天） | `https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.000001&klt=5&fqt=1&lmt=100&end=20500101&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57` | `klines[]` 每条 `时间,开,收,高,低,成交量,成交额`，`lmt=100` 约覆盖两个交易日（每天 48 根） |
| 日 K（备用） | 同上 `klt=101&lmt=3` | 取昨日全天成交额；也可用来判断「今天是不是交易日」（最后一根的日期 == 今天） |

`secid` 前缀：`1.` 沪市、`0.` 深市。上证 `1.000001`、深成 `0.399001`、创业板 `0.399006`、沪深300 `1.000300`。

实时性：`ulist.np` 在盘中返回的是当前快照（实测与东财网页同步，延迟秒级），非交易时段返回收盘值。

**踩坑记录**：分时接口 `stock/trends2/get`（一分钟分时、可跨天）在本机环境下连接被直接断开（curl 和 urllib 都是 `RemoteDisconnected`），不要用；5 分钟 K 线 `klt=5` 能达到同样目的。

## 2. 「放量 / 缩量」口径

- **成交额** = 上证指数 `f6` + 深证成指 `f6`（沪市 + 深市，单位元，显示时换算成亿 / 万亿）。不含北交所，跟东财首页「两市成交」口径一致。
- **昨日同时段** = 昨日的 5 分钟 K 线里，时间 ≤ 当前时刻（向下取整到 5 分钟）的成交额累加。两市各算一次再相加。
- **比值** `ratio = 今日累计 / 昨日同时段累计 − 1`：
  - `≥ +10%` → 标「▲ 放量」（琥珀色 pill）
  - `≤ −10%` → 标「▼ 缩量」（灰色描边 pill）
  - 中间 → 不打标签，只显示带符号的百分比
- 阈值 10% 先写死，做完看一周实际数据再决定要不要做成配置。
- **集合竞价（9:15–9:25）** 不算比值（成交额还太小），显示「开盘后开始比较成交量」。
- **收盘后 / 非交易日** 比值改为「全天 vs 昨日全天」，文案跟着变。

## 3. 交易时段判断（后端）

只按本机时间 + 星期判断，不查节假日表：

| 阶段 | 时间 | 显示 |
|---|---|---|
| `pre` | 9:15–9:30 | 集合竞价（黄点） |
| `open` | 9:30–11:30、13:00–15:00 | 盘中（绿点） |
| `lunch` | 11:30–13:00 | 午间休市（灰点） |
| `closed` | 其它工作日时间 | 已收盘（灰点） |
| `holiday` | 周六日 | 休市（灰点） |

法定节假日落在工作日时会被误判成「已收盘」，靠日 K 兜底：最后一根日 K 的日期不是今天就按 `holiday` 处理，并把「昨日」改成最后一根日 K 的日期。这样够用，不引入节假日表。

## 4. 刷新节奏

由**后端**控制，前端只被动收：

- `open` / `pre`：每 **10 秒**拉一次 `ulist.np`；每 **60 秒**拉一次两市 5 分钟 K 线（算昨日同时段）。
- `lunch`：每 60 秒拉一次（数据不动，主要是为了 13:00 能及时切回 `open`）。
- `closed` / `holiday`：只在服务启动时和跨天时各拉一次，之后不请求。
- 失败退避：连续失败按 10s → 30s → 60s → 5min 拉长，成功后回到正常间隔。失败时保留上次数据并淡化显示，条上给一句错误文案（不弹窗、不影响动态列表）。

网页端不再单独轮询：后端拉到新数据就通过现有 SSE 通道广播一个新事件 `("market", {...})`，与 `status` 事件同级；`/api/snapshot` 里也带一份当前值供首屏和重连合并。这样多个标签页 / 平板副屏共用一份请求，不会放大对东财的请求量。

## 5. 接口契约

新增 SSE 事件 / snapshot 字段 `market`，形状：

```json
{
  "phase": "open",                      // pre | open | lunch | closed | holiday
  "at": "14:07:30",                     // 后端本次成功拉取的时间
  "trade_date": "2026-09-18",           // 本条数据所属交易日
  "idx": [
    {"code": "000001", "nm": "上证",   "px": 3911.87,  "chg": 0.94},
    {"code": "399001", "nm": "深成",   "px": 13640.87, "chg": 1.72},
    {"code": "399006", "nm": "创业板", "px": 3372.68,  "chg": 2.25},
    {"code": "000300", "nm": "沪深300","px": 4507.39,  "chg": 1.06}
  ],
  "amt": 1462000000000,                 // 两市成交额，元；集合竞价阶段也给
  "vol": {                              // 算不出来时为 null（集合竞价 / 昨日 K 线没拉到）
    "ratio": 0.124,                     // 今日 / 昨日同时段 − 1
    "tag": "more",                      // more | less | flat
    "vs": "vs 昨日同时段"               // 后端直接给文案，前端不做时段判断
  },
  "err": null                           // 失败时是一句中文，前端原样显示
}
```

`nm` 由后端给短名（`f14` 返回的是「上证指数 / 深证成指 / 创业板指 / 沪深300」，条上放不下）。`--mock` 模式下 `MockCore` 给一份固定值 + 每次刷新随机抖动，保证离线也能看到条。

## 6. 前端

- 位置：`.app` 网格新增第一行 `auto`，条本身 `grid-column: 1 / -1`，在顶栏之上；收起后该行高 0，布局回到现状。
- 折叠：右侧 ✕ 收起，状态存 `localStorage diting.market`（`show|hide`，经 `store` 小工具）；收起后在顶栏「⋯」菜单里加「显示大盘」恢复。
- 响应式按信息价值逐级减（对应现有断点，改成 `@media`）：
  - `≤1150px`：去掉沪深300、「vs 昨日同时段」文字、迷你双柱
  - `≤900px`：再去掉点位、刷新时间、阶段文字、「两市」标签
  - `≤480px`：再去掉成交额和 ✕
- 颜色：指数红涨绿跌沿用 `--stock-red` / `--ok`；放量 pill 用 `--warn` 系（需在 `:root` 新增 `--warn-soft`），缩量 pill 灰色描边——放/缩量本身不分好坏，刻意不用红绿。
- 收盘 / 非交易日 / 接口失败三种状态给 `.stale`，数字 `opacity: .55`。
- 迷你双柱：今日 vs 昨日同时段，长的那根撑满 44px，另一根按比例；今日那根用 `--accent`。

## 7. 不做的事

- 不做个股 / 板块 / 涨跌家数 / 北向资金——这是股吧动态监控工具，大盘条只是抬头看一眼的背景信息，不往行情软件方向走。
- 不做前端直连东财（违反「浏览器只请求 127.0.0.1」的约束，平板副屏也用不了）。
- 不做节假日表。
- 不做 tkinter 版。
